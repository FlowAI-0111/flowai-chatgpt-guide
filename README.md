## ChatGPT Plus 和 Pro 怎么选？

先看你每天用 ChatGPT 做什么，以及现有套餐是否经常影响工作。写作、学习、资料整理与编程的使用频率不同，不必只因套餐名称更高就升级。

- **日常使用，先比较 Plus。** 查看当前功能是否满足自己的任务，再判断是否需要更高用量。
- **经常高强度使用，再比较 Pro。** 重点看实际使用需求、当前可用权益和预算，而不是把更高档位理解为所有功能都无限使用。
- **准备使用 Codex，先分清登录方式。** ChatGPT 登录与 API Key 的计费入口不同，购买前可查[套餐选择与 Codex 说明](docs/choose-plan.md)。

详细对比：[ChatGPT Plus/Pro 套餐怎么选](docs/choose-plan.md)。具体模型、额度与价格会更新，文档不固定承诺某个版本一直可用。

## 用支付宝购买 ChatGPT 会员，怎么给自己的账号开通？

下面以 FlowAI 当前 Plus 自助月卡为例。其他商品的人工交付或联系开通方式，在第一步单独说明。

### 第一步：确认套餐和要开通的账号

确认 ChatGPT 中登录的是自己准备开通的账号，再核对商品的套餐周期、适用条件和交付方式。有尚未到期的会员时，先看续费条件。

- [ChatGPT Plus 月卡：查看当前价格与开通条件](https://ai0111.com/products/chatgpt%20plus)
- [ChatGPT Pro5x 月卡：查看当前价格与开通条件](https://ai0111.com/products/ChatGPT%20Pro5x)
- [ChatGPT Pro20x 月卡：查看当前价格与开通条件](https://ai0111.com/products/ChatGPT%20Pro20)
- [ChatGPT Plus 年卡：查看12个月服务与人工交付说明](https://ai0111.com/products/gpt-plus-annual)
- [ChatGPT Pro 500美元档：先联系客服确认开通安排](https://ai0111.com/products/chatgpt-pro-500)

**月卡、年卡和人工联系商品，购买步骤有区别。** Plus 年卡先按商品页下单，付款后人工交付年卡 CDK，再按说明提交开通；Pro 500美元档则在商品页选数量与开票需求，点击「联系客服开通」，复制购买信息后由客服确认付款和处理安排。该联系入口不会直接创建商城订单或扣款。年卡是 FlowAI 提供的12个月服务商品，不据此推定 OpenAI 官方有个人 Plus 年付套餐。

### 第二步：选择登录购买或游客购买

已有 FlowAI 账号的用户，先登录再核对会员优惠；不用重新注册。暂不注册也可以按页面选择游客购买，并准确填写下单联系方式。

**商城账号用于购买和查单，ChatGPT 账号用于使用会员。** 两者用途不同，不要把商城登录信息当成 ChatGPT 登录信息。

### 第三步：确认优惠、发票和付款金额

核对商品、数量与优惠。需要开发票时，在结算中选择对应选项，再看最终应付金额。支付宝、花呗和信用卡的可选方式以实际收银台为准。

首页或商品页的金额与选择发票后的应付金额应分别核对，完整解释见[会员优惠与开票说明](docs/orders-and-invoices.md#为什么登录后或选择开票后价格会变化)。

### 第四步：在订单中领取兑换码并提交开通

付款确认后，当前自助月卡会自动发放 CDK（兑换码）。打开订单详情，从订单提供的入口按说明使用兑换码，核对账号并提交开通任务。

收到兑换码后，还需要完成开通步骤；只看到商城“已发货”，不能据此判断 ChatGPT 会员已经生效。兑换码、密码和登录会话不要发到公开评论或 GitHub。

### 第五步：回 ChatGPT 核对会员状态

任务完成后，回到同一个 ChatGPT 账号查看套餐状态。如账号套餐与购买内容不符，保留订单信息，通过商城“联系客服”核查。

更详细的操作与异常排查：[ChatGPT 充值、购买与续费完整步骤](docs/buy-and-renew.md)。

## 购买前，哪些信息值得看清楚？

| 关注点 | 在页面上核对的内容 |
|---|---|
| 给谁开通 | 是自己的账号开通，还是另行交付账号 |
| 买的是什么 | 套餐名称、周期与适用条件 |
| 怎样完成交付 | 自动发货兑换码，还是人工处理；领取后还有哪些步骤 |
| 最终付多少钱 | 会员优惠、数量、发票选项与结算金额 |
| 付款后在哪里找订单 | 游客查单或登录后的“我的订单” |
| 遇到问题怎么办 | 商品售后说明、订单信息和商城客服入口 |

这些信息能帮助你在付款前理解流程。能开发票、能查单本身不等于所有使用或交付问题都有同一种处理结果，具体按商品和订单说明执行。

## 常见问题

### 没有海外信用卡，可以用支付宝购买吗？

FlowAI 商城支持支付宝、花呗及信用卡付款。先查看所选商品是否适用于自己的账号，再按结算页面付款；收银台没有显示的付款方式不要自行假定可用。

### 可以开发票吗？

可以。下单时先选择发票选项并核对金额，再按订单页提示填写开票资料。开票资料、费用和进度说明见[查单与开票指南](docs/orders-and-invoices.md)。

### 已有账号，但很久没登录，还要重新注册吗？

不需要。使用原 FlowAI 商城账号登录即可；从注册页进入时，可以点“已有账号？直接登录”。登录后重新确认商品优惠，再继续购买。

### 付款时没注册，后来注册为什么看不到订单？

游客订单按下单时的身份查询。后来注册商城账号不会自动合并以前的游客订单，请用下单时的联系方式进入[游客查单](https://ai0111.com/guest/orders)。登录购买的订单则在[我的订单](https://ai0111.com/me/orders)查看。

### 已经收到兑换码，为什么 ChatGPT 还不是 Plus？

兑换码发货与会员开通是两个步骤。先确认是否按订单说明提交了开通任务，再核对任务状态及 ChatGPT 账号；具体看[付款后未开通的排查步骤](docs/buy-and-renew.md#已付款但还不能使用先确定停在哪一步)。

### 会员没到期，可以提前续费吗？

先看新商品是否支持当前账号状态，以及剩余时间如何处理。不要默认提前购买或使用兑换码就会自动叠加天数，说明不清楚时先向商城客服核实。

### Plus/Pro 会员和 API 余额是一回事吗？

不是同一个计费入口。需要使用 API Key 的用户，可先读[套餐与认证说明](docs/choose-plan.md)，确认自己要购买的内容。
