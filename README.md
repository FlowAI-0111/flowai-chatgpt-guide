## 先分清三个账号和凭据

| 名称 | 用途 | 容易混淆的地方 |
|---|---|---|
| ChatGPT 账号 | 登录和使用 ChatGPT，核对实际套餐 | 要开通的是你确认过的那个账号 |
| FlowAI 商城账号 | 登录购买、使用符合条件的会员优惠、查看会员订单 | 后来注册商城账号，不会自动把以前的游客订单转入个人中心 |
| CDK（兑换码） | 按订单说明提交对应开通任务 | 兑换码不是登录密码；收到码后仍需完成订单说明中的步骤 |

以 FlowAI 当前 Plus 月卡的自助开通为例：

**确认商品与账号 → 付款 → 在订单领取兑换码 → 按说明提交开通 → 回 ChatGPT 核对套餐。**

人工交付商品按各自订单提示处理。不要把一种商品的流程套用到所有套餐。

## 这份指南怎样使用

- **先解决具体问题。** 三篇专题都可独立阅读，表格和步骤无需登录即可查看。
- **查实时信息。** 商品价格、库存、优惠、开票费用和交付条件，请看商城当前页面及最终结算金额；本文不保存容易过期的价格表。
- **区分文档与售后。** 文档更正可提交 Pull Request；实际订单问题请用商城“联系客服”。不要在 GitHub 公开发布联系方式、订单详情、兑换码、密码或登录会话。
- **查产品依据。** 套餐和认证相关信息参考 [OpenAI 套餐说明](https://learn.chatgpt.com/zh-Hans/docs/pricing) 与 [认证说明](https://learn.chatgpt.com/docs/auth)，功能与可用性以当前账号和官方规则为准。

## 已经选好套餐？

可以在 [FlowAI 商城](https://ai0111.com/)查看对应商品。商城支持支付宝付款，包括花呗、信用卡付款方式；具体可选方式看收银台。有开票需求时，在结算前选择并核对金额。已有账号的用户先登录再购买；游客也可以直接下单。
